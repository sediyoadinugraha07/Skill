## Ringkasan
Pengguna memilih nama GeoSpectra (Multi-Sensor Remote Sensing Processor; padanan Mandarin usulan 地谱 dìpǔ, belum ditinjau penutur asli) untuk seluruh pengembangan berikutnya. Aplikasi lahir dari kerja sama Undiksha dan Xinyang Normal University; rencana pengajuan HKI.

## Keputusan
- Diganti: judul jendela, dialog Tentang (menyebut dua institusi), teks kredit laporan Excel di core/*, judul README, nama exe di build_windows.spec, 2 kunci i18n (total 3968).
- Tidak diganti: folder kode `landsat_processor` dan awalan zip `landsat_processor_vNNN.zip`, agar jejak versi dan jalur impor utuh. Ditolak: rename paket sekarang karena berisiko memutus impor dan tidak perlu untuk nama tampilan.
- Ditolak sebagai nama: Tejacitra, Usnacitra (terlalu berat ke termal / bahasa lokal), GanXin (Gan = Jiangxi, menanam nama institusi), TerraSpectra (bentrok nama satelit Terra), OmniScene/万象 (juga Vientiane).
